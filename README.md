# Breast Cancer Outcome Predictor

> **Exploratory Data Analysis and Predictive Modeling for Breast Tumor Classification (Benign vs. Malignant).**

This project analyzes the "Breast Cancer Wisconsin (Diagnostic)" dataset using Python, Pandas, and Scikit-Learn. The goal is to build Machine Learning models (Random Forest and Logistic Regression) to predict tumor diagnosis with high accuracy, including a comprehensive EDA phase and result visualization.

##  Project Overview

- **Dataset:** 569 samples with 30+ numeric features derived from cell nucleus images.
- **Objective:** Binary classification (Benign vs. Malignant).
- **Approach:** Data cleaning, EDA, feature scaling, and model evaluation.
- **Best Model:** Logistic Regression (Accuracy: 96.5%, ROC-AUC: 99.6%).
